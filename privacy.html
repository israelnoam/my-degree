בקצרה

"התואר שלי" היא אפליקציית רשת לתכנון תואר בטכניון. אין לה שרת שמחזיק את הנתונים שלך ואין לה מסד נתונים משותף. כל משתמש רואה רק את הנתונים שלו: הם נשמרים בדפדפן שלו ובתיקייה מוסתרת בגוגל דרייב שלו. בעל האפליקציה ומשתמשים אחרים לא יכולים לראות אותם.

איזה מידע נשמר ואיפה

  • הקורסים, הציונים, המשימות, מערכת השעות, קורות החיים וההגדרות שאתה מכניס: בזיכרון של הדפדפן במכשיר שלך, ואם התחברת עם Google, גם בקובץ בתיקיית האפליקציה המוסתרת (appDataFolder) בגוגל דרייב שלך, כדי לסנכרן בין המכשירים שלך.
  • גיליון הציונים (PDF) נקרא בתוך הדפדפן בלבד. הקובץ עצמו לא נשלח לשום מקום; רק הקורסים והציונים שבו נשמרים כמו שתואר למעלה.
  • מפתח AI (Anthropic), אם הכנסת: נשמר רק במכשיר שבו הכנסת אותו, ולא מסתנכרן.

הרשאות Google ולמה הן נחוצות

  • drive.appdata: לשמור ולקרוא את קובץ הנתונים של האפליקציה בתיקייה המוסתרת שלה בדרייב שלך. האפליקציה לא רואה שום קובץ אחר בדרייב.
  • calendar.readonly: להציג את האירועים מהיומנים שלך במערכת השעות. קריאה בלבד: האפליקציה לא יוצרת, משנה או מוחקת אירועים.
  • tasks: סנכרון דו-כיווני של המשימות שלך עם Google Tasks (יצירה, עדכון וסימון משימות שאתה מנהל באפליקציה).

הגישה נעשית ישירות מהדפדפן שלך אל Google. הנתונים מ-Google משמשים רק להצגת התכונות האלה לך, לא נמכרים, לא משמשים לפרסום, ולא מועברים לאף אחד.

השימוש של האפליקציה במידע שמתקבל מ-Google APIs עומד ב-Google API Services User Data Policy, כולל דרישות ה-Limited Use.

שירותים חיצוניים

  • יומנים לפי קישור (Apple / Outlook): הקישור שאתה מוסיף נשמר בנתונים שלך. כדי לקרוא אותו, שרת האפליקציה מוריד את קובץ היומן ומעביר אותו ישר לדפדפן שלך, בלי לשמור אותו.
  • AI (Claude של Anthropic): רק כשאתה משתמש בתכונת AI (יועץ, קורות חיים, בניית תוכנית מחוברת, סריקת הזדמנויות), הנתונים הרלוונטיים נשלחים ישירות מהדפדפן ל-Anthropic עם המפתח שלך, לפי מדיניות הפרטיות של Anthropic.
  • CheeseFork ואתרי הטכניון: מידע ציבורי על קורסים ומערכות נטען משם. לא נשלח אליהם מידע אישי.

English summary

"My Degree" is a web app for planning a Technion degree. It has no backend database: each user's data stays in their own browser and in the hidden app folder (drive.appdata) of their own Google Drive, so no one else, including the app's owner, can see it.

Google scopes: drive.appdata (store the app's own data file), calendar.readonly (show your events in the timetable, read-only), tasks (two-way sync of your tasks). Google user data is used only to provide these features to you, is never sold, never used for advertising, and never transferred to others. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Calendar links (ICS) are fetched by a pass-through server function that stores nothing. AI features send the relevant data straight from your browser to Anthropic, using your own API key, only when you use them. Grade-sheet PDFs are read in the browser and never uploaded.

Delete your data: disconnect in Settings, delete the app's hidden data in Google Drive settings → Manage apps, and revoke access at myaccount.google.com/permissions. Contact: israelnoam2001@gmail.com.
